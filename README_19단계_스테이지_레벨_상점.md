# 댕댕대작전 19단계 — 스테이지 선택 · 레벨 · 상점

## 🗺️ 스테이지 선택
- 첫 화면에서 이름을 쓰고 **🗺️ 혼자 연습하기** → 스테이지 10곳 중에서 골라요.
- 처음에는 스테이지 1만 열려 있고, 이기면 다음 스테이지가 열려요.
- 별: 이기면 ★1, 우리 기지 체력이 50% 이상이면 ★2, 80% 이상이면 ★3.
- 스테이지가 높을수록 적이 강해지고 나오는 적도 달라요 (스테이지 9·10은 흡혈귀·박쥐).
- 끝나면 ▶ 다음 스테이지 / 🔁 다시 하기 / 🗺️ 스테이지 선택 / 🛒 상점.
- 교사 방: 대기실의 **스테이지** 칸에서 반 전체가 싸울 스테이지를 고를 수 있어요 (기본: 웨이브마다 자동으로 바뀜).

## ⭐ 레벨
- 경험치(EXP): 문제 정답 +10, 승리 +50, 별 1개마다 +20, 져도 +10.
- 레벨 1→2는 100, 그다음은 레벨마다 50씩 더 필요해요 (2→3: 150, 3→4: 200 …).
- 레벨이 오르면 전투를 시작할 때 코인이 레벨마다 +10 늘어나요 (최대 +150). 교사 방 개인전에서도 적용돼요.
- 첫 화면과 전투 화면 왼쪽 아래에 레벨과 경험치 막대가 보여요.

## 🛒 상점
- 모은 코인: 문제 정답 +10, 승리하면 별 × 100 (처음 깬 스테이지는 +100 더).
- 아이템 (전투 중 아래쪽 아이템 칸을 눌러 사용)
  | 아이템 | 가격 | 효과 |
  |---|---|---|
  | 🍗 체력 회복 | 300 | 우리 기지 체력 +400 |
  | 🦴 공격력 강화 | 200 | 30초 동안 우리 편 공격력 1.3배 |
  | 🛡️ 방어력 강화 | 250 | 30초 동안 기지가 받는 피해 절반 |
  | 🎯 스킬 충전 | 400 | 전투 코인 +250 (발사 OK!! 한 번) |

## 기록은 어디에 저장되나요?
레벨·코인·아이템·별은 **그 태블릿(브라우저)에 이름별로** 저장돼요. 같은 태블릿에서 같은 이름으로 들어오면 이어져요. 다른 기기나 브라우저 데이터 삭제 시에는 처음부터 시작해요.
