# 👑 댕댕대작전 24단계: 교사 관리실 (TEACHER CONTROL CENTER)

보내 주신 교사 관리실 시안대로 교사 화면을 새로 만들었어요. 대기실과 게임 중 화면이 하나로 합쳐졌어요.

- **위**: 마스코트, 로고, "교사 관리실" 배너, 게임 방식 표시, 전체화면, 🏠 끝내기(방 닫기)
- **숫자 카드 5개**: 방 코드(⧉ 복사), 참가 학생 n/30명, 진행 전장, 평균 정답률, 경과 시간
- **왼쪽 메뉴**
  - 🎮 전장 현황: 팀·학생별 전장 카드(팀 깃발 색, WAVE, HP% 막대, 남은 시간, 팀원) + **▶ 관전하기**
  - 👥 학생 현황: 팀 순서 학생 표
  - 🔀 팀 배정: 1~6팀 깃발 칸, 학생마다 팀 바꾸기
  - ⚙️ 게임 설정: 개인전/협동전/대항전, 스테이지(자동 + 10개 그림)
  - 📖 문제 관리: 지금 문제 수, XLSX/CSV 올리기
  - 📊 결과 보기: 순위표 + CSV 다운로드
- **오른쪽 🏆 영어 퀴즈 랭킹**: 맞힌 개수 순, 1~3등 메달, 정답률 색(초록/노랑/빨강)
- **아래 버튼**: ▶ 게임 시작(시작 후엔 🔄 처음부터) · ❚❚ 일시정지/다시 진행 · ⟳ 대기실로 · ⬇ 결과 CSV 다운로드
  작은 버튼: 자동 배정 · 수동 배정 · 방 코드 복사 · 게임 설정
- **관전하기**: 고른 전장의 실제 전투 화면을 창으로 크게 띄워 실시간으로 봐요(서버에 `watch` 기능 추가).

바뀐 파일: `client/src/TeacherCenter.jsx`(새 파일), `client/src/main.jsx`, `client/src/style.css`(24단계), `server/index.js`, 그림 `client/public/tc/`
