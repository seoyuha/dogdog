# 댕댕대작전 17단계 — 새 캐릭터 그림 · 태블릿 화면 · 처음부터/끝내기

## 1. 캐릭터 그림과 움직임
- 보내 준 일러스트에서 캐릭터를 깔끔하게 잘라 `client/public/hd/`에 넣었어요 (배경·글자·칸 선 없이).
  - 강아지 6종: 시바 견습병, 코기 방패병, 허스키 궁수, 푸들 마법사, 리트리버 기사, 늑대 용사 (로고에 가려진 부분도 정리)
  - 적 7종: 초록 슬라임, 투척 고블린, 수정 거미, 방패 고블린, 해골 강아지, 어둠 마법사, 보스 골렘
- 픽셀 그림 대신 부드러운 일러스트를 쓰고, 화면을 1.5배로 그려 태블릿에서 또렷해요.
- 움직임은 매 순간 부드럽게 이어지도록 새로 만들었어요.
  - 대기: 숨 쉬듯 살짝 커졌다 작아짐 · 걷기: 통통 튀는 걸음과 몸 흔들림
  - 공격(근접): 웅크렸다 → 앞으로 찌르고 → 제자리 · 공격(활·마법): 몸을 젖혔다 → 쏘면서 반동
  - 피격: 빨갛게 번쩍이며 뒤로 밀림 · 쓰러짐: 뒤로 넘어지며 사라짐
  - 동작이 바뀔 때 뚝 끊기지 않고 자연스럽게 섞여요.
- 아군은 오른쪽, 적은 왼쪽을 보고 걸어요. 유닛 카드 그림도 새 그림으로 바꿨어요.
- 쓰지 않게 된 옛 그림(SVG 애니메이션 210장, 잘못 잘린 적 그림 등)은 뺐어요. 파일이 약 50개로 줄어 GitHub 웹에서도 한 번에 올릴 수 있어요.

## 2. 태블릿 한 화면
- 전투 중에는 전투 화면 · 유닛 소환 · 영어 퀴즈가 스크롤 없이 한 화면에 보여요 (가로 1280×720 기준 확인).
- 남은 시간·웨이브는 전투 화면 위 줄에 모았어요. 전투 화면 양옆 빈 곳은 배경을 흐리게 채워요.
- 세로로 들면 유닛이 한 줄로 나오고 퀴즈는 아래에 나와요.

## 3. 처음부터 · 나가기 · 끝내기
- 학생 🔄 **처음부터**: 혼자 연습과 개인전에서 내 전투만 처음부터 다시 시작
- 교사 🔄 **처음부터 다시 시작**: 교사 관제실에서 모든 학생 전투를 한 번에 새로 시작
- 교사 ⏹ **끝내기**(위쪽): 방을 닫고 처음 화면으로. 학생들도 "선생님이 방을 닫았어요" 안내와 함께 처음 화면으로 돌아가요.
- 학생 🏠 **나가기**(위쪽): 언제든 처음 화면으로 (전투 중이면 한 번 물어봐요)

## 4. 실행이 안 되던 문제 고침 (10/22 오후)
- **🎮 혼자 연습은 서버 없이도 돼요.** 이제 이 기기 안에서 전투가 돌아가서 GitHub Pages·Netlify 주소, 서버가 꺼졌을 때, 와이파이가 불안할 때도 바로 시작돼요.
- **서버에 연결되지 않으면 이유를 알려 줘요.** 예전에는 버튼을 눌러도 아무 반응이 없었어요. 이제 "게임 서버에 연결되지 않았어요…" 안내가 나오고, 서버가 7초 동안 답이 없으면 그것도 알려 줘요.
- **교사 PIN 기본값**: 서버에 `TEACHER_PIN`을 따로 정하지 않으면 **123456**으로 들어가요 (Windows_실행.bat와 같음). 수업 전에 바꾸는 것을 추천해요.
- 서버만 켜고 화면 파일을 만들지 않았을 때 빈 화면 대신 해결 방법을 보여 줘요.
