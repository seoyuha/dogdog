## 🔧 점검 후 고친 것 (그림·애니메이션 파일은 그대로)
1. **그림이 하나도 안 나오던 문제**: 캐릭터·배경 그림이 `client/public` 폴더에 있는데 Vite가 그 폴더를 몰라서 220개 그림이 모두 열리지 않았어요. `vite.config.js`에 그림 폴더 위치(`publicDir`)를 알려 줬어요.
2. **보스가 여러 마리 나오던 문제**: 보스 웨이브(5·10·15…)에 보스가 1마리가 아니라 2~5마리씩 나왔어요. 1마리만 나오게 고쳤어요.
3. **정답이 1→2→3→4번 순서로 반복되던 문제**: 문제 파일 40문제의 정답 번호가 1,2,3,4,1,2,3,4… 순서라 규칙만 알면 다 맞힐 수 있었어요. 문제를 낼 때마다 보기 순서를 섞어요. (문제 파일은 그대로)
4. **와이파이가 끊기거나 새로고침하면 다시 못 들어오던 문제**: 전투 중에 끊기면 "이미 시작한 방입니다"로 막혔어요. 이제 **같은 이름 + 같은 방 코드**로 들어오면 하던 전투로 돌아가요. 잠깐 끊긴 것은 자동으로 다시 연결돼요. 끊긴 학생은 교사 화면에 📴로 보여요.
5. **교사가 잠깐 끊기면 학생에게 교사 권한이 넘어가던 문제**: 교사가 1분 넘게 돌아오지 않을 때만 넘겨요. 교사도 같은 이름으로 다시 들어오면 교사 화면으로 돌아가요.
6. **같은 이름으로 두 명이 들어오던 문제**: 같은 방에 같은 이름은 들어올 수 없어요.
7. **학생 없이 '전투 시작'을 누르면 방이 멈추던 문제**: 학생이 없으면 시작하지 않고 안내해요.
8. **팀 대항전에서 상대 팀이 비어 있어도 시작되던 문제**: 1팀 vs 2팀, 3팀 vs 4팀, 5팀 vs 6팀 중 상대 팀에 학생이 없으면 안내해요. (처음엔 모두 1팀이라 꼭 팀을 나눠야 해요)
9. **문제 업로드가 다른 반 방에도 적용되던 문제**: 올린 문제는 그 방에만 적용돼요.
10. **엑셀에서 'CSV'로 저장한 파일의 한글이 깨지던 문제**: 한글 윈도우 엑셀 CSV(ANSI)도 읽어요.
11. **`npm start`(배포용)로 실행하면 화면이 안 나오던 문제**: 실행 위치와 상관없이 `dist`와 `questions` 폴더를 찾아요. (먼저 `npm run build` 필요)

## 🌐 인터넷에 올리기 (Render)
- GitHub에 이 폴더 안의 파일을 올린 뒤(node_modules 제외), Render → New → Web Service
- Language **Node** · Build Command **`npm install && npm run build`** · Start Command **`npm start`** · Instance Type **Free**
- **Environment → `TEACHER_PIN`** 에 교사 PIN(예: 6자리 숫자)을 꼭 넣어 주세요. 없으면 아무도 교사 방을 만들 수 없어요.
- 학생·교사 모두 Render 주소로 접속해요. (교사는 '교사 방 만들기')

## ⚖️ 난이도 조절 (6학년이 적당히 이길 수 있게)
원래는 개인전에서 4초마다 문제를 다 맞혀도 2분 안에 기지가 무너져서 이길 수 없었어요. 아래처럼 바꿨어요. (그림은 그대로)

- **적 웨이브**: 30초 간격(점점 빨라져 최소 18초), 한 번에 1~2마리. 적 체력은 웨이브마다 조금씩 강해져요.
- **보스**: 5웨이브마다 1마리, 체력을 낮춤.
- **적 기지**: 체력 2400 (우리 기지 1600). 시간이 끝나면 남은 체력 '비율'로 승부를 정해요.
- **기지 방어탑**: 기지 가까이 온 적을 화살로 쏴요. 적 기지 탑은 절반 세기.
- **코인**: 저절로 쌓이는 코인 초당 1.2 → 4 (개인전·협동전). 문제 정답 코인은 그대로.
- **유닛**: 값은 그대로. 비싼 유닛이 값어치를 하도록 체력·공격력을 올리고, 시바 견습병만 계속 뽑는 방법은 약하게.
- **협동 팀전**: 팀 인원이 많을수록 적 기지·적 체력이 커져요.

컴퓨터로 학생 행동을 흉내 내어 수백 판 돌려 본 결과 (개인전, 10분):
| 학생 | 문제 푸는 속도·정답률 | 이긴 비율 |
|---|---|---|
| 잘하는 학생 | 5~7초, 88% | 약 90% |
| 보통 학생 | 7~11초, 72% | 약 70% |
| 어려워하는 학생 | 10~16초, 55% | 약 50% |
(시바 견습병만 계속 뽑으면 잘 지고, 여러 유닛을 섞어 쓰면 잘 이겨요.)
