# 댕댕대작전 16단계 보안 및 접속 테스트

## 수정
- 교사 방 생성 시 `TEACHER_PIN` 환경변수와 PIN 일치 여부 검사. 기본값을 서버에 내장하지 않았습니다.
- 학생/교사 재접속은 암호학적 난수로 생성한 48자리 세션 토큰으로만 허용합니다. 동일 이름만으로는 복구할 수 없습니다.
- 토큰은 해당 브라우저 localStorage에 방별 저장됩니다. 공유 기기에서는 브라우저 데이터를 정리하세요.
- 팀별 최대 5명 배정 검증, 최대 학생 30명 검증.
- 재접속 시 현재 전투 상태와 새 문제를 전송합니다.

## Windows
`Windows_실행.bat`는 편의상 PIN 123456을 설정합니다. **실제 수업 전 반드시 PIN을 바꾸세요.**
명령 프롬프트에서 `set TEACHER_PIN=원하는PIN`을 실행한 다음 같은 창에서 `npm run dev`를 실행할 수 있습니다.

## 테스트
`npm test` : 전투 엔진 테스트
`npm run build` : React/Vite 번들 생성
`npm run test:load` : 서버 실행 상태에서 30명 가상 접속 시험

## 주의
브라우저가 아닌 서버의 인증·권한 검증을 우선했습니다. 30대 갤럭시탭 실기기 테스트는 별도입니다.
