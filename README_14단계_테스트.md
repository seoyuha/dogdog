# 댕댕대작전 14단계 — 안정화 및 검증

이번 단계는 13단계 전투 그래픽을 유지하고 실제 수업 전 테스트 가능성을 높이는 데 집중합니다.

## 수정 내용
- 서버 엔진에 존재하지 않는 유닛 ID로 소환할 수 없도록 검증 추가
- 잘못된 시간 간격(dt) 입력을 방어
- 시작되지 않은 전투에서는 정답 제출 불가
- 상태 확인 API(`/api/health`)에 버전 표시
- Node.js 내장 테스트 러너를 이용한 엔진 자동 테스트 6개 추가

## 테스트
Node.js 20 이상 설치 후 프로젝트 폴더에서 `npm test`를 실행하세요. 서버 전투 엔진 테스트는 외부 패키지 설치 없이 실행됩니다.

## 실제 게임 실행
1. Node.js LTS 설치
2. Windows_실행.bat 실행 (최초 실행 시 npm 패키지 설치 필요)
3. 교사 PC `http://localhost:5173`
4. 학생 태블릿: 교사 PC와 동일 네트워크에서 `http://교사PC_IP:5173`

## 검증 한계
현재 실행 환경에서 npm 패키지 설치가 완료되지 않아 React/Vite 빌드, 브라우저 시각효과 및 30명 실제 접속 부하 시험은 미검증입니다. 이 파일을 검증 완료된 학교 배포판으로 취급하지 마세요.
