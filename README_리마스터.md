# 댕댕대작전 11단계: 제공 이미지 반영판

## 이미지 적용
- 제공된 `Gemini_Generated_Image_rt5vdwrt5vdwrt5v.png` 시안에서 고대 숲·수정 황무지·어둠의 제단 배경을 각각 잘라 `client/public/remaster/stage1~3.webp`로 저장했습니다.
- 제공된 `Gemini_Generated_Image_su1ap2su1ap2su1a.png`의 강아지 스프라이트 시트에서 코기, 시바 궁수, 푸들 마법사의 대표 그림을 분리했습니다.
- 적 캐릭터는 제공된 적 시트에서 대표 이미지를 추출해 웨이브에 따라 표시합니다.
- 배경: 웨이브 1~4 숲 / 5~8 황무지 / 9 이후 제단.
- 기존 영어 문제, 코인, 실시간 멀티플레이, AI, 전투 엔진을 보존합니다.

## 중요한 제한
원본 ZIP `daengdaeng_final_game_assets.zip`에는 실제 PNG 프레임이 아닌 텍스트 설정만 들어 있습니다. 따라서 이번 버전은 채팅에 첨부된 시안 이미지에서 배경 및 대표 캐릭터를 추출하여 연결한 것입니다. 모든 캐릭터의 연속 프레임을 정확히 복원한 것은 아니며, 전투 애니메이션은 기존 구현과 혼합되어 있습니다. 일부 적은 웨이브에 맞춰 외형만 변경되며 AI 특성은 기존 서버 로직입니다.

## Windows 실행
1. Node.js LTS 설치
2. 압축 해제 후 `Windows_실행.bat` 실행
3. `http://localhost:5173` 접속

교사 PC와 학생 태블릿은 동일 네트워크에 있어야 합니다. 30명 동시 접속은 실제 교실 환경에서 검증해야 합니다.
