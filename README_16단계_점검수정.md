# 🔧 16단계 점검 후 고친 것 (그림 파일은 하나도 바꾸지 않았어요)

1. **30명 접속 테스트(`npm run test:load`)가 항상 실패하던 문제**
   학생이 처음엔 모두 1팀이라 '팀별 최대 5명' 검사에 걸려 전투가 시작되지 않았어요.
   → 교사 대기실에 **🎲 자동 팀 나누기** 버튼을 만들었어요 (협동·대항전에서 팀당 최대 5명으로 고르게, 대항전은 짝수 팀).
   30명 테스트도 자동 팀 나누기를 거쳐 통과해요.
2. **지난 수업 방 때문에 매번 오류가 뜨던 문제**
   서버가 다시 켜지거나 다음 시간이 되면 태블릿을 열 때마다 "이전 방 자동 복귀 실패: 방 코드를 찾을 수 없습니다"가 계속 떴어요.
   → 복귀에 실패하면 저장된 정보를 지우고 처음 화면으로 조용히 돌아가요.
3. **예전 복구 정보 때문에 다시 참가할 수 없던 문제**
   교사가 '대기실로'를 누르면 끊겨 있던 학생 기록이 지워지는데, 그 학생 태블릿은 예전 복구 정보를 계속 보내서 새 이름으로도 들어올 수 없었어요.
   → 대기실에서는 이름으로 새로 참가할 수 있고, 맞지 않는 복구 정보는 지워요.
4. **와이파이가 잠깐 끊겼다 이어질 때 '이미 다른 기기에서 접속 중'으로 막힐 수 있던 문제**
   태블릿 와이파이가 끊기면 서버는 수십 초 동안 아직 접속 중으로 알 수 있어요.
   → 올바른 복구 정보(토큰)로 다시 연결하면 새 연결로 넘겨받고 예전 연결은 끊어요. 처음 열 때 복귀 요청도 한 번만 보내요.
5. **난이도가 다시 너무 어려워진 문제**
   12~13단계에서 생긴 적 종류(고블린·거미는 원거리, 어둠 마법사는 공격력 1.45배 등) 때문에 보통 학생 승률이 약 70% → 16%로 떨어졌어요.
   → `server/engine.js`의 `AI.enemyAtk`(0.7), `AI.enemyHp`(0.75), `passive`(4.5)로 맞췄어요. 적 종류별 특징은 그대로예요.
   | 학생 | 이긴 비율(개인전) |
   |---|---|
   | 잘하는 학생 | 약 90% |
   | 보통 학생 | 약 70% |
   | 어려워하는 학생 | 약 60% |
6. **Render에 올리면 교사 방을 만들 수 없던 문제(안내 누락)**
   교사 PIN이 서버 설정(`TEACHER_PIN`)에만 있어서, Render에 그대로 올리면 PIN이 없어 방을 만들 수 없어요.
   → README_실행방법.md의 Render 안내에 `TEACHER_PIN` 설정을 넣었어요.

## 그림 파일 문제 (고치지 않고 그대로 둠)
`client/public/sprites/`의 적 그림(고블린·방패 고블린·해골 강아지·어둠 마법사·골렘 등)에 시트 칸 테두리, 옆 칸 그림 일부, "Idle", "Skeleton Dog", "Dark Mage" 같은 글자가 같이 들어 있어요. 11단계 때 잘못 잘린 그림을 그대로 이어 쓴 것이라, 원본 시트에서 다시 잘라야 해요.

## 교사 PIN 바꾸기

- Render: Environment → `TEACHER_PIN` 값 바꾸기
