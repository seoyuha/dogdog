# 🐶 댕댕대작전 23단계: 새 그래픽 테마 (첫 시작 화면 제외)

첨부해 주신 그래픽 시안(에셋 시트, 전투 UI 시안)으로 게임 화면 전체의 그림과 디자인을 바꿨어요.
**게임 규칙·서버·문제 프로그램은 그대로**이고, 첫 시작 화면도 그대로예요.

## 바뀐 화면
- **위쪽 바**: 새 로고, LESSON 엠블럼, ❤️ 우리 팀 기지 HP 막대(초록→노랑→빨강), 파란 집·전체화면 버튼
- **전장**: 우리 기지가 수정 성으로 바뀌고, 체력에 따라 3단계(멀쩡함 → 금 감 → 부서짐)로 변해요.
  오른쪽 위 💀 Wave 배지와 남은 시간, 끝나면 CLEAR!/FAILED 그림이 떠요.
- **아래 3칸** (시안 배치 그대로)
  - 왼쪽 **유닛 소환**: 발바닥 코인 + 댕댕이 카드 6장
  - 가운데 **Question**: 나무 테두리 양피지 판 + 노란 리본, 큰 보기 버튼 4개
  - 오른쪽 **스킬 / 아이템**: 아이템 4칸(물약·불꽃·방패·번개) + **댕댕 필살기!** 버튼 (예전 '발사 OK!!')
- **결과**: CLEAR!/FAILED 그림, 별 3개, 보물상자, 8초 뒤 자동 다음 전투
- **대기실·교사 관제실·상점·카드덱·스테이지 창**: 하늘/풀밭 배경, 나무 테두리 판, 노란·파란 버튼으로 통일
- 세로 태블릿: 전장 → Question → (유닛 소환 | 스킬·아이템) 순서

## 그림 파일
- `client/public/ui2/` 안에 시안에서 잘라 배경을 지운 그림 40여 개(로고, 버튼, 아이콘, 성, CLEAR/FAILED, 상자, 리본 등)
- 바뀐 코드: `client/src/main.jsx`, `client/src/Battle.jsx`, `client/src/style.css`(맨 아래 23단계), `client/src/profile.js`(문구 하나)
