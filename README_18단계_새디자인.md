## 바뀐 것
- **배경**: 웨이브 2개마다 스테이지가 바뀌고, 왼쪽 위에 "스테이지 N 이름"이 나와요. 기지는 배경 그림 속 기지를 그대로 써요.
- **적**: 스테이지마다 나오는 적이 달라요 (1 슬라임·고블린 … 8 거미·박쥐, 9 흡혈귀·마법사, 10 흡혈귀·박쥐). 5웨이브마다 골렘 보스.
- **움직임**: 적은 시트의 실제 프레임으로 걷고·공격하고·맞고·쓰러져요. 공격·피격 동작은 끝까지 보여 준 뒤 걷기로 자연스럽게 이어져요.
- **화면 구성** (태블릿 가로 한 화면):
  - 위: 로고 · 나가기 버튼
  - 가운데: 전투 화면 + 코인(○ / 800) · 남은 시간
  - 아래 왼쪽: 유닛 카드(코인이 모이는 막대) + **발사 OK!!** 버튼(코인 250) + 처음부터
  - 아래 오른쪽: **영어 문제** 판 (난이도 별, 보상 코인, 번호 동그라미 보기)
  - 답하면 "정답입니다! / 틀렸습니다!" 그림과 정답이 나와요.
- **첫 화면**: 타이틀 그림으로 바꿨어요.
