# 댕댕대작전 13단계: 적 고유 공격 이펙트

12단계에서 이어지는 소스 프로젝트입니다.

## 변경사항
- 서버 공격 이벤트에 `enemyType` 및 `targetId` 추가. 화면 효과는 실제 서버 공격 이벤트에 맞춰 실행됩니다.
- 슬라임: 초록 점액탄, 고블린: 돌 투척, 수정 거미: 보라색 수정 파편, 방패 고블린: 방패 충격파.
- 해골 강아지: 뼈 투척, 어둠 마법사: 보라색 마법 구체, 골렘: 거대한 바위 충격 및 화면 흔들림.
- 기존 투명 PNG 스프라이트와 5종 동작 애니메이션, 영어 퀴즈, 팀전 기능 유지.

## 제약
스프라이트는 원본 시안에서 분리·가공한 프레임이므로 완전한 손그림 연속 동작이 아닙니다.
실제 브라우저에서 30명 동시 접속 부하 검증은 별도 필요합니다.

## 실행
Windows_실행.bat를 실행하거나 Node.js 설치 후 `npm install` → `npm run dev`.
교사 PC에서 http://localhost:5173 으로 접속.
