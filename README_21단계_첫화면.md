# 🐶 댕댕대작전 21단계: 첫 화면(타이틀·게임 모드 선택)

디자인 ① "타이틀·게임 모드 선택" 그대로 첫 화면을 바꿨어요.

- 화면 가득 타이틀 그림(로고 + 강아지들 + 성 배경)이 나와요.
- 아래에 큰 버튼 4개가 있어요.
  - ⚔️ **개인전** 혼자서 도전! → 이름 입력 → 스테이지 선택 → 바로 전투 (서버 없이도 돼요)
  - 👥 **팀전** 함께 승리! → 이름 + 방 코드 → 참가
  - 🤝 **협동전** 친구와 방어! → 이름 + 방 코드 → 참가
  - 🧑‍🏫 **교사 모드** 수업 관리! → 게임 방식(개인전/팀전/협동전) 고르기 + 교사 PIN → 방 만들기
- 버튼을 누르면 작은 창이 열리고, ✕를 누르면 다시 타이틀로 돌아가요.
- 게임이나 방에서 나가면 타이틀 화면으로 돌아와요.
- 태블릿 가로: 버튼 4개가 한 줄 / 세로: 2×2로 배치돼요.

## 바뀐 파일
- `client/src/main.jsx` (첫 화면 구조)
- `client/src/style.css` (맨 아래 "21단계" 부분)
- `client/public/ui/title.webp` (타이틀 그림)

> 타이틀 그림은 디자인 시안에서 잘라낸 것이라 조금 흐릴 수 있어요.
> 더 선명한 타이틀 이미지(가로 1920px 정도)를 `client/public/ui/title.webp` 이름으로 바꿔 넣으면 바로 선명해져요.
