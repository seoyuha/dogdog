# 댕댕대작전 12단계: 실제 스프라이트 애니메이션 및 적 유형

## 새로 적용한 내용
- 사용자 첨부 시안에서 이전 단계에 분리해둔 투명 캐릭터 이미지를 사용해 10종의 6열×5행 PNG 스프라이트 시트 생성
- 각 캐릭터의 대기/이동/공격/피격/KO 상태를 Phaser 스프라이트 애니메이션으로 재생
- 1~4웨이브: 슬라임/투척 고블린, 5~8웨이브: 수정 거미/방패 고블린, 9웨이브 이후: 해골 강아지/어둠 마법사
- 5웨이브 간격의 보스는 골렘 외형을 사용하며, 적 유형별 체력/공격력/이동속도 보정 적용
- PVP는 상대 팀도 강아지 유닛으로 표시하도록 수정
- 기존 강아지 3종(코기, 시바 궁수, 푸들) 외의 아군은 기존 SVG 프레임 사용

## 한계
첨부 시안은 여러 프레임이 섞인 이미지 판넬로, 독립된 원본 동작 프레임이 아닙니다. 이번 30프레임/캐릭터는 추출된 대표 그림에 위치·기울기·크기 변형을 적용한 애니메이션이며, 관절별 손그림 동작과는 다릅니다. 일부 가장자리 추출 품질이 불완전할 수 있습니다.

## 실행
Node.js LTS 설치 후 `Windows_실행.bat` 실행, http://localhost:5173 접속. 실제 30명 수업 전 브라우저와 동시 접속 테스트 권장.
