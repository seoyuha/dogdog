# 댕댕대작전 15단계 — 실전 접속 검증 준비

## 변경 내용
- 서버 연결 상태 표시 및 재연결 시 안내
- 교사 전용 학생별 정답 수/시도 수/정답률 CSV 내보내기
- 연결 끊긴 교사 권한이 학생에게 자동 이전되지 않도록 보안 수정
- 전투 종료/재시작 이후 예약된 다음 문제가 잘못 전달되지 않도록 수정
- 30명 동시 Socket.IO 접속, 방 입장, 문제 수신, 전투 상태 전송을 확인하는 자동 부하 테스트 스크립트 추가
- `/api/status` 서버 상태 확인 API

## Windows 실행
1. Node.js LTS 설치
2. `Windows_실행.bat` 실행
3. 교사 PC: http://localhost:5173
4. 학생 태블릿: http://교사PC_IP:5173 (같은 네트워크)

## 검증 명령
- `npm test` : 전투 엔진 단위 테스트
- `npm run build` : React/Vite 빌드
- `npm run server` : 서버 실행 (별도 터미널)
- `npm run test:load` : 서버가 실행 중일 때 30명 가상 접속 검증

## 검증 범위 유의
자동 30명 테스트는 같은 PC에서 가상 소켓 30개를 연결합니다. 실제 갤럭시탭 30대, 학교 Wi-Fi, 각 기기의 화면 렌더링 성능은 별도 현장 테스트가 필요합니다.
