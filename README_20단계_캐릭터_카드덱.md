## 카드덱
- 처음 카드 6장: 군댕이·닌자댕이·궁수댕이·탐정댕이·간호댕이·요리댕이
- 🃏 카드덱 화면: 전투에 데려갈 6마리 고르기(카드를 눌러 넣기/빼기), ⬆ 강화(150→300→500→800 코인)
- 🛒 상점 → 🃏 캐릭터 카드 탭: 서퍼 300 · 천사 400 · 기사 500 · 마법 500 · 대포 700 · 왕 1000
- 전투 아래쪽 카드 = 내 덱 6장 (역할 색 테두리, Lv 표시)
- 교사 방에서도 학생 자기 덱·카드 레벨로 싸워요

## 캐릭터별 애니메이션·효과
- 동작: 대기(숨쉬기) → 걷기(걷기·달리기 그림을 번갈아) → 공격(준비→공격 그림+찌르기) → 스킬(점프+스킬 그림) → 피격(빨간 번쩍+피격 그림) → 쓰러짐(쓰러짐 그림+사라짐)
- 효과: 왕 황금 베기 / 기사 파란 초승달·회전 베기 / 군 흙먼지·수류탄 폭발 / 닌자 수리검 / 궁수 화살·불화살 3연발 / 마법 마법 구름+범위 고리 / 대포 포탄 포물선+폭발+연기 / 요리 음식·프라이팬 던지기 / 서퍼 물결 파도 / 탐정 별+"약점" / 간호 하트 치료 / 천사 빛기둥+별 치료
