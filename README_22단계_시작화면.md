# 🐶 댕댕대작전 22단계: 새 시작 화면

보내 주신 시작 화면 시안(DaengDaeng_Start_UI)을 그대로 실제 게임 첫 화면으로 넣었어요.
그림은 고화질 원본을 그대로 쓰고(`client/public/ui/start.webp`), 그 위에 입력칸과 버튼만 겹쳐 놓았어요.

| 그림 속 버튼 | 실제 동작 |
|---|---|
| 내 이름 / 방 코드 입력칸 | 직접 입력 (방 코드는 자동으로 대문자) |
| 🎮 학생 게임 입장 | 이름 + 방 코드로 선생님 방(팀전·협동전·개인전)에 참가 |
| 🎓 혼자 연습하기 | 이름만 넣고 스테이지 선택 → 혼자 전투 (서버 없이도 됨) |
| 📖 게임 방법 보기 | 게임 방법 안내 창 |
| 🧑‍🏫 교사용 방 만들기 | 게임 방식(개인전/팀전/협동전) + 교사 PIN → 방 만들기 |

- 이름을 넣으면 아래에 레벨·코인·🃏카드덱·🛒상점 줄이 나와요.
- 빠진 내용이 있으면 "게임 입장" 위에 노란 안내가 떠요(누르면 사라짐).
- 그림 비율을 지키며 화면에 맞춰지고, 남는 곳은 흐린 배경으로 채워요. 태블릿은 가로 모드가 가장 좋아요.
- 바뀐 파일: `client/src/main.jsx`, `client/src/style.css`(맨 아래 22단계), `client/public/ui/start.webp`

## 22-2: 게임 중간에 들어와도 바로 시작
교사가 **⚔️ 전투 시작**을 누른 뒤에 들어온 학생도 기다리지 않고 바로 전투에 들어가요.
- 개인전: 그 학생만의 새 전투가 바로 시작돼요.
- 협동전: 아직 싸우고 있는 팀 중 인원이 가장 적은 팀(최대 5명)에 들어가요. 모든 팀이 꽉 찼으면 새 팀이 생겨요.
  팀원이 늘면 적 기지 체력도 늘지만, 지금 깎인 비율은 그대로라서 갑자기 회복되지 않아요.
- 팀 대항전: 진행 중인 대결에서 인원이 적은 쪽 팀에 들어가요.
- 게임 중에 끊긴 학생이 같은 이름으로 다시 들어오면 원래 팀·전투로 돌아가요.

## 22-3: '혼자 연습하기' 버튼 빼기
- 시작 화면 그림에서 보라색 '혼자 연습하기' 버튼을 지우고, 남은 버튼 3개를 세로로 늘려 패널을 빈틈없이 채웠어요(글자·아이콘 크기는 그대로).
- 학생은 이름 + 방 코드로만 들어와요. (개인전은 교사가 방을 만들 때 '개인전'을 고르면 돼요)
